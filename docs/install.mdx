---
title: "Install"
description: "Build Amgi and the amgi command from source."
---

Amgi is early and changing quickly, so there are no downloads for now: build it from
source.

<Steps>
  <Step title="Get what it needs">
    macOS 26 on Apple Silicon, Xcode, [Rust](https://rustup.rs) and [Bun](https://bun.sh).
  </Step>
  <Step title="Build and install">
    ```sh
    git clone https://github.com/alisheryeginbay/amgi
    cd amgi
    make install                 # build Amgi.app and put it in /Applications
    cargo install --path cli     # the amgi command
    ```
    Run `git pull` and `make install` again to update.
  </Step>
  <Step title="Open a collection">
    Press <kbd>⌘O</kbd> and pick a folder for your cards. See
    [Introduction](/#a-collection-is-a-folder) for how it's laid out.
  </Step>
</Steps>

See [CONTRIBUTING.md](https://github.com/alisheryeginbay/amgi/blob/main/CONTRIBUTING.md)
for the project layout, tests and running a development build.
