`amgi` reads a collection from the terminal. Install it with `cargo install --path cli`.

```sh
amgi status                  # cards left today, by deck, and about how long; --short for one line, empty when done
amgi check                   # problems in the deck files as path:line: message; exits 1 if any
amgi lint                    # deck files that break the rules in amgi.toml; --fix fixes them
amgi fmt                     # deck files in one layout; --check lists those that would change
amgi search deck:french is:due   # cards matching a search, such as is:leech
amgi decks                   # every deck with due, learning, new and total counts
amgi tags                    # every tag with its card count
amgi info cards/geography.md:12   # a card's schedule and history, by id, path:line or a search
amgi stats                   # streak, time, retention, recent reviews and the next two weeks; --deck for one deck
amgi prune                   # files in media that no card links to; --trash moves them to the Trash
amgi diff                    # cards added, changed and removed since the last commit
```

`search` takes the [search syntax](#searching) below.

`stats` shows the last 30 days of reviews on one line; `--days 365` shows a year as a
calendar, a column per week, darker for busier days. `--time` shades the days by time
spent instead of reviews. Once some reviews are [timed](/studying#time-spent-studying),
`stats` also says how long today took, about how long the cards left today will take,
and your pace over the last 30 days, and the forecast says about how long each day will
take.

`stats --deck lang/french` counts only that deck and its subdecks: its cards, its
reviews, and its streak, which is the days you reviewed any card in it. Today's new cards
and due cards are capped by the collection's daily limits, which every deck shares
(see [Limit reviews per day](/studying#when-cards-are-due)).

`prune` reads the links in every Markdown file in the collection, including cards
commented out and decks outside `cards`, so a file any of them shows is kept. It only
looks inside the `media` folder, and leaves hidden files such as `.DS_Store` alone.

Every command takes `--json`. `search` exits 1 when nothing matches, and `--ids` prints
only card ids. `--dir` (or `AMGI_DIR`) picks the collection; without it, `amgi` uses the
folder holding `.amgi.sqlite` at or above the current one, or else the folder last opened
in the app.

Output is in color on a terminal and plain when piped. `--color always` or `never`
overrides that, as do the `NO_COLOR` and `CLICOLOR_FORCE` environment variables.

## Searching

Every word in a search must match the card's question, answer, tags or note fields,
ignoring case and accents. Words can also be filters:

| Search | Finds cards |
|---|---|
| `"capital of"` | with that exact phrase |
| `-paris` | without `paris` (works before any filter, too) |
| `#verbs`, `#lang*` | tagged `verbs`; with a tag starting with `lang` |
| `deck:french` | in a deck named `french` or under one, such as `lang/french/words` |
| `q:paris`, `a:"to go"` | with that text in the question or answer only |
| `meaning:apple`, `wordmeaning:go` | from a note whose field of that name has the text; leave out spaces in the name |
| `is:new` `is:due` `is:suspended` `is:leech` `is:cloze` `is:basic` | in that state or of that kind |
| `is:mature` | next due 21 or more days after its last review, as in Anki |
| `lapses>3`, `reviews<=5` | compared by count (`<`, `<=`, `>`, `>=`, `=`) |
| `due<1`, `due<7`, `due<0` | due today; within 7 days; overdue (before today). New cards have no due date |
| `interval>=7` | next due at least 7 days after its last review. New cards have no interval |

Anything else, such as `12:30`, is searched as text.

## Lint

`amgi lint` checks how the deck files are written, against the rules in `amgi.toml` at
the collection root, and lists what breaks them as `path:line:column: message`. It exits
1 if anything is left. `amgi lint --fix` fixes what it can, in the files.

```toml amgi.toml
[lint]
media-links = "absolute"
missing-media = true
tags = true
```

- `media-links`: `"absolute"`, the default, wants media linked from the collection root,
  as `![](@/media/photo.jpg)`, so links keep working when a deck moves. `--fix` rewrites
  `../media/photo.jpg` that way, and cards keep their history. `"any"` turns the rule off.
- `missing-media`: on by default, lists links to files that don't exist, or that lead
  out of the collection, since those don't show. When another file has the name, such as
  `photo.jpeg` for `photo.jpg` or the same file in another folder, it's suggested. These
  aren't fixed for you; `false` turns the rule off.
- `tags`: on by default, lists a tag given twice on a card, and a tag written with
  different capitals across the collection, such as `#Korean` and `#korean`. `--fix`
  drops the repeat and writes the most used spelling; a deck's front matter tags are
  listed but left to you. `false` turns the rule off.

Without `amgi.toml`, every rule has its default. Links in code blocks and code spans are
text, so they're left alone. `--fix` never changes a card's id: a file whose cards would
get new ids, and so lose their history, is left as it is and listed.

## Format

`amgi fmt` rewrites the deck files in one layout: no trailing spaces or Windows line
endings, each card a blank line after the one before, a card's tags a space apart, and
one newline at the end of the file. Code blocks keep their blank lines. `amgi fmt
--check` lists the files that would change instead, and exits 1 if there are any, for a
git hook.

The cards stay exactly the same, ids included, so no history is lost: a file whose
cards would change isn't written, and is listed.

tags or moving a card to another deck shows as a change. Editing a question shows the
old card removed and a new one added, since that starts the card over. Files git ignores
are left out.

```sh
amgi diff                    # since the last commit, as the files on disk are now
amgi diff --staged           # what the next commit holds
amgi diff main~5             # since another commit
amgi diff v1 v2              # between two commits
amgi diff --check            # exits 1 if cards with review history are removed
amgi diff --reviewed         # only the removed cards with review history
```

A removed card that you've reviewed shows how many reviews it has. Its history stays in
the database, but no card uses it any more, as when a question is edited. `--check` exits
1 when that happens, to catch it before a commit; moving cards, fixing answers and
changing tags keep their history, so they pass. `--reviewed` lists only those cards,
for when a long diff hides them.

`--json` lists `added`, `removed` and `changed` cards; each removed one has its number of
`reviews`, and each changed one has the card `before` and `changes`, any of `question`,
`answer`, `tags` and `deck`.

This git hook (save it as `.git/hooks/pre-commit` in the collection's repository and make
it executable) stops a commit that would leave review history unused, and shows which
cards. Commit with `--no-verify` when that's what you meant.

```sh
#!/bin/sh
amgi diff --staged --check
```

This git hook (save it as `.git/hooks/prepare-commit-msg` in the collection's repository
and make it executable) starts each commit message with what the commit does to the
cards, such as `feat(french): add 12 cards`. It needs [jq](https://jqlang.org), and runs
`amgi` at the top of the repository, so pass `--dir` if the collection is in a folder
inside it.

```sh
#!/bin/sh
case "$2" in message|merge|squash|commit) exit 0 ;; esac  # keep -m, merges and amends
subject=$(amgi diff --staged --json | jq -r '
  [(.added | length), (.changed | length), (.removed | length)] as [$a, $c, $r]
  | select($a + $c + $r > 0)
  | (.added + [.changed[].card] + .removed | map(.deck) | unique) as $decks
  | (if $a > 0 then "feat" elif $c > 0 then "fix" else "chore" end)
    + (if ($decks | length) == 1 then "(\($decks[0]))" else "" end) + ": "
    + ([if $a > 0 then "add \($a)" else empty end,
        if $c > 0 then "update \($c)" else empty end,
        if $r > 0 then "remove \($r)" else empty end] | join(", "))
    + (if $a + $c + $r == 1 then " card" else " cards" end)')
[ -n "$subject" ] || exit 0
{ echo "$subject"; cat "$1"; } > "$1.tmp" && mv "$1.tmp" "$1"
```
