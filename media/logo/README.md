# Amgi logo

A forget-me-not, the flower whose name asks you to remember, pressed flat like one kept in a book:
five blue petals, a navy shadow printed under them, a dashed vein on each petal, and a white eye
with a yellow centre.

## Files

| File | Use |
|---|---|
| `amgi-symbol.svg` | The mark. 48 px and up. |
| `amgi-symbol-small.svg` | Without veins, a little larger, for 16–40 px. `favicon.svg` is a copy. |
| `amgi-symbol-mono.svg`, `-black`, `-white` | One colour: printing, embossing, monochrome UI. The eye is a real hole. |
| `amgi-horizontal.svg` | Symbol and "Amgi" on light backgrounds. |
| `amgi-horizontal-dark.svg` | The same with a white wordmark, for dark backgrounds. |
| `amgi-horizontal-mono.svg` | The lockup in navy alone. |

| `amgi-social-preview.svg` | 1280×640 card for GitHub and social links: the lockup and tagline on cream, inside GitHub's 80 px safe border. |
| `png/` | PNG exports of the above. |

## Colour

| | HEX | RGB |
|---|---|---|
| Forget-me-not blue | `#5B8DEF` | 91 141 239 |
| Ink navy | `#1B2F5E` | 27 47 94 |
| Eye yellow | `#FFC53D` | 255 197 61 |

Navy on white and white on navy both pass WCAG AAA. Blue is for the petals only, never for text.

## Wordmark

"Amgi" is the README's handwriting: [Caveat](https://fonts.google.com/specimen/Caveat) (SIL Open
Font License) as outlines, so no font is needed. The word, from the top of the A to the baseline,
is centred on the flower, with a gap of about a fifth of the symbol's width between them.

## Using it

- **Clear space:** keep half a petal's width (about a sixth of the symbol) free on every side.
- **Minimum size:** 16 px for `amgi-symbol-small`, 48 px for `amgi-symbol`, 120 px wide for the lockup.
- **Backgrounds:** white, cream, light greys, and navy or darker for the full-colour mark. On mid-tones
  or photos, use a one-colour version.
- **Don't:** recolour the petals, move or drop the shadow on its own, rotate the flower, stretch it,
  add effects, or set "Amgi" in another font.
